# Comparison with deployed provenance methods (VISION, test split)

Generated by `baselines_vision.py` + `compare_vision.js`. 1000 photos; test split: 685 photos, 8905 unedited copies, 11928 visible edits. Every copy and edit was rebuilt by the code of make_vision.py and checked against its stored record (same file size, same edit box). SecureCam score recomputed here: AUC 0.977318 (results_vision.json: 0.977318).

## C2PA hard binding (c2pa-python, test certificate)

- Signed originals: **1000/1000 Trusted** (manifest 28395-389674 bytes); unsigned originals: 1000 with no manifest.
- Real platform files of VISION (3000: WhatsApp, Facebook high/low): EXIF kept in 0, APP11 (where C2PA is stored) kept in 0. Segments kept: real_whatsapp 0xe0 (1000); real_facebook_high 0xe0+0xe2+0xed (1000); real_facebook_low 0xe0+0xe2+0xed (1000). So on these platforms a C2PA manifest is removed and the copy has no credentials, edited or not.
- Best case for C2PA, the manifest put back into each JPEG copy: unedited copies valid **0/7535** (Invalid:assertion.dataHash.mismatch: 7535); visible edits valid 0/11928 (Invalid:assertion.dataHash.mismatch: 11928). The hash binding cannot tell a recompressed copy from an edit, and does not say where a change is.

## PDQ (Meta, 256-bit perceptual hash)

- Threshold 31 bits (ThreatExchange recommendation): unedited accepted **8905/8905 (100.00%)**, visible edits rejected **1962/11928 (16.4%; 95% CI 15.8-17.1%)**
- Threshold 10 bits (calibrated: 99.5% of unedited calibration copies): unedited accepted **8876/8905 (99.67%)**, visible edits rejected **7274/11928 (61.0%; 95% CI 60.1-61.9%)**
- AUC 0.8950; unedited accepted at 1% / 5% of edits accepted: 0.0% / 19.5%.
- Different photos: 0 of 499500 pairs of originals within 31 bits (closest 42); 0 of 22605 test copies within 31 bits of another photo (closest 36). PDQ gives no location for a change.

## TrustMark (Adobe, C2PA soft-binding watermark; model Q, BCH_5, 61-bit payload)

- Watermarking changes the pixels: PSNR 42.9 dB on average (35.6-50.6). Read back from the watermarked file: 996/1000; found in unwatermarked originals: 25/1000.
- Unedited simulated copies: payload recovered **6799/6850 (99.26%)**, wrong payload 0, not found 51. (Real platform files cannot be used: they were made from the unwatermarked photo.)
- Visible edits: payload recovered **11726/11928 (98.3%)**, i.e. linked to the original's credentials with no sign of the edit; wrong payload 3; not found 199 (1.7%).

## AUC with 95% bootstrap intervals (200 resamples of the test photos, as in results_vision)

- SecureCam regions: 0.977 (0.974-0.980)
- PDQ: 0.895 (0.890-0.901); PDQ minus SecureCam: -0.088 to -0.077
